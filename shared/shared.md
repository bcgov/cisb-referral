# Shared Directory

This directory contains shared resources, utilities, and components that are used across the CISB Referral application.

## Contents

- Common utilities
- Shared components
- Constants and configuration
- Type definitions
- Helper functions

## Usage

Import shared resources as needed throughout the application to maintain consistency and avoid code duplication.

```typescript
// Example import
import { someUtility } from "shared/utilities";
import { SomeComponent } from "shared/components";
```

## Guidelines

- Keep this directory organized with clear subdirectories
- Document all shared code thoroughly
- Ensure shared components are reusable and flexible
- Test shared utilities comprehensively
